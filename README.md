# cryPIto

## About the Project

**cryPIto** is a user interface project developed for an HCI (Human-Computer Interaction) Lab Project. The project focuses on designing an interactive and user-friendly interface while applying fundamental Human-Computer Interaction principles.

## Features

* User-friendly interface
* Interactive navigation
* Responsive web interface
* Organized page layout
* Interactive UI components

## Technologies Used

* HTML
* CSS
* JavaScript
* Figma

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Navigate to the `html` folder.
4. Open the main HTML file in a web browser.

For the best development experience, the project can be opened using Visual Studio Code with the Live Server extension.
